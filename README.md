# CIRCULAR GARDEN
##  Description
### This program is a calculator for the area of a circular garden. It uses functions like *math.pi, math.pow(), math.sqrt(), math.floor(),* and *math.ceil()*. By entering the required inputs, it shows the area, circumference, and the square root of the area of the circular garden.

## How to Run
### To run this program, it will ask first for the radius of the garden. Then, it will calculate the area, circumference, and square root of the area for the garden.

## Input Needed
### Inputs needed is the radius of the circle. This alone can calculate all the Outputs needed for the circular garden.

## Sample Output

### Input: 5
###    The area of the circular garden is: 78.54 square meters
###    The circumference of the circular garden is: 31.42 meters
###    The square root of the area of the circular garden is: 8.86
###    Area rounded down: 78 square meters
###    Area rounded up: 79 square meters
